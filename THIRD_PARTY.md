# Third-party dependencies

Runtime dependencies and transitive dependencies retain their original licenses. npm installs include their LICENSE files. This package is independently implemented; Basic Memory, QMD, Letta, OpenClaw and Graphiti are architecture references and are not bundled.

The distribution also includes the existing complete notice collection in [THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt), preserved without changes. The newly bundled sql.js JavaScript/WASM reader carries its upstream license separately in [licenses/sql.js-LICENSE](licenses/sql.js-LICENSE). Keep these notices with redistributed source and build outputs.

Embedding models are optional future adapters and are not downloaded by this release.
