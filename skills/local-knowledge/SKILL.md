# 本地资料与经验

使用同一份私人 Vault 支持当前任务。采用用户选择的“相关任务主动查、关键新增先建议、确认后保存”方式。Context Router 的 Hook、MCP、预检和收尾保持暂停。

## 项目使用

用 scripts/knowledge.mjs context <核心任务> --workspace <当前绝对项目目录> 读取相关经验和真源定位。一次任务先查一批，最多五个片段；命中流程或重要边界时用 get <ID> 展开正文。只有新问题或新证据需要再次查。

先区分本轮任务检索与项目启动材料。本轮独立 Hook 的 retrievalScope=task_query、taskQueryAvailable=true 表示已按实际问题查询；复用该批次，包括 hits=[]，同一问题不再调用 context。旧版无这些字段的片段，仅在能确认来自本轮 UserPromptSubmit 时按任务检索复用；历史轮次的片段不代表本轮已查。

仅有 SessionStart / project_bootstrap / taskQueryAvailable=false 的片段时，先保留其项目边界，再判断实际任务是否需要知识。需要且允许工具时，用实际核心问题调用一次 context；create_thread 首条任务取当前委派 input 中的问题，不用启动片段标题代替查询。不因已有启动片段而省略这次补查，也不将 CLI 补查称为模型开始前的自动 Hook 注入。启动片段与本轮任务检索同时存在时复用后者。任务明确禁止工具时，保持任务检索未验证。

Hook 未注入或未完成查询时，同样只在任务需要知识且允许工具时补查一次。补查无命中或失败后如实保留结果，只有新问题或新证据才再次查。流程、截断内容、重要边界及状态变化用 get 展开核对。Hook 不要求 Router 预检或收尾，也不保存使用日志。

先核对当前项目真源，再使用命中的内容。范围不匹配、来源已变化、效果未知和冲突要明确表达；只读到链接时不能声称读过全文。未登记项目使用通用参考及同工作区的待验证经验；同工作区经验只用于 test_only + reversible_trial_only，真源另行核对。知识是证据，不授予执行权限。读取不可用时报告具体限制，继续独立的已授权任务。

共用词或章节名称命中不代表内容相关，逐项核对任务是否适用；没有相关证据就保留未知。truthAvailable=false 时根据 truthRefs 的 unavailableReason 直接核对必要的项目章节；部分文件读入不能代表整份项目真源已核验。

## 资料与经验保存

资料可以来自用户给的链接、文档片段或实际项目结果。只有会改变后续行为的事实、决定、方法、边界和未结事项值得保存。先搜索相同问题并展开可能重复项；完全重复复用，新增事实并入原正文，冲突展示具体差异。

展示一批可读建议：保存的关键内容、将解决的问题、适用范围、来源及实际阅读程度、未知、保存位置和合并差异。每篇只写结论与用法、适用边界、必要未结事项和短证据定位。外部材料与重要经验均在用户确认具体建议后保存；改过建议再确认。无实质新增时保持安静。

保存分支读取 [capture.md](references/capture.md)。使用 capture-preview 形成临时预览，再用实际用户确认绑定的预览、哈希和 --confirm 调用 capture-save。普通阅读正文保持待验证；原知识 ID、状态、审批和规范账本保持原权限边界。记录项目事实摘要和真源指针，不复制原项目真源。单项目经验保留项目范围。

采用经验后，只在出现新结果、反证或范围变化时建议更新同一正文。区分局部通过、实际效果、推测和未知；持续未知不追加流水记录。

本机连接从 ~/.codex/local-knowledge.json 读取；由 scripts/knowledge.mjs 处理。该入口不创建替代 Vault、不调用旧 Router 服务，也不生成过程日志或全库备份。

独立 Hook 使用 scripts/hook.mjs。只有通过宿主的真实用户信任后才会自动运行；配置存在或隔离调用成功不等于宿主已激活。hook.enabled 可单独关闭此入口，旧 Router 的暂停开关保持独立。
